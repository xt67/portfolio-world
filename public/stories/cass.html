From a question to a result

A visitor asks a question in everyday language. A local model proposes SQL, and PostgreSQL executes the accepted query using a restricted role. The interface streams the answer so the visitor can see progress.

The database role matters because an instruction to a model cannot enforce database permissions. The application also checks query structure and bounds execution time and returned rows.

What has been checked

  • Turns natural-language questions into SQL with a configured local model.
  • Applies read-only transactions, query timeouts, row limits and deployment authentication.
  • Includes streaming response handling and restricted-role PostgreSQL tests.

Generated SQL still needs review. Simple representative queries passed with the tested local model; general accuracy is not guaranteed.
